# ADR 0001 — Alpha

Installer Alpha و Local Alpha دو Role در Conversation هستند. عملیات واقعی توسط CLI و Application Services انجام می‌شود. Database و Context منبع بازیابی هستند. حفظ Conversation مسیر مطلوب است؛ ادامه در Conversation جدید نیز الزامی است. MVP به AI API پولی وابسته نیست و Planner دستی مجاز است.
